✨ Key Features & Technical Highlights
🎨 Modern Design Tokens: Built using custom CSS variables (--ss-bg, --ss-cyan, --ss-green, etc.) optimized for a dark-mode-first developer aesthetic with high contrast ratios.

⚡ Zero Framework Dependencies: Written in vanilla HTML, CSS, and JavaScript (~7 KB JS footprint), ensuring lightning-fast load times and near-instant initial paint.

📊 Dynamic Statistical Counters: Intersection Observer-driven counting animations that trigger smoothly when elements enter the viewport.

✨ 3D Tilt Card Micro-Interactions: Custom pointer tracking that maps radial lighting gradients and subtle hardware-accelerated 3D transforms onto expertise cards.

📈 Interactive Timeline & Accordions: Cleanly structured career history rail with smooth CSS grid transitions and mobile-friendly accordion toggles.

🌌 Procedural Canvas Particle Field: Lightweight background node network with dynamic lines and auto-throttling to preserve battery life and main-thread performance when out of view.

♿ Accessibility & Reduced Motion Support: Fully responsive design with explicit support for prefers-reduced-motion, screen readers, keyboard navigation (tabindex, focus rings), and mobile touch devices.

🧩 WordPress / Elementor Compatibility: Scoped entirely under the .ss-site container wrapper so rules never conflict with existing theme stylesheets.

🌐 WordPress Deployment Guide (Optional)
If you plan to host this template on a WordPress site using Elementor or a custom theme:

Copy the CSS styles inside the <style> block of preview.html.

Paste them into Appearance → Customize → Additional CSS (the .ss-site scoping wrapper will prevent styles from leaking into your theme).

Insert the HTML markup into an HTML or Custom Code block inside your page builder.
